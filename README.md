## 🔐 Features

### 1. Authentication System

- User Registration & Login APIs
- Password hashing using `bcrypt`
- JWT-based authentication (stateless)

**Auth Flow:**

```
User Registers → User Logs In → Receives JWT → JWT used for all protected APIs
```

---

### 2. Role-Based Access Control (RBAC)

**Roles:** `user` | `admin`

| Role  | Permissions                                    |
| ----- | ---------------------------------------------- |
| User  | Create, read, update, delete **own** tasks     |
| Admin | Manage all users & control task lifecycle      |

**Admin-only endpoint:**

```http
GET /api/v1/admin/users
```

---

### 3. Task Management — CRUD + Lifecycle

Each task follows a controlled lifecycle:

```
pending → running → completed
```

| Status      | Set By         |
| ----------- | -------------- |
| `pending`   | Auto (on create) |
| `running`   | Admin only     |
| `completed` | Admin only     |

> ⚠️ Users can create and update task content; **only Admins can change task status.**

---

### 4. Task API Endpoints

```http
POST   /api/v1/tasks              → Create task (status = pending)
GET    /api/v1/tasks              → Get user-specific tasks
GET    /api/v1/tasks/{id}         → Get single task
PUT    /api/v1/tasks/{id}         → Update task (user)
DELETE /api/v1/tasks/{id}         → Delete task

PATCH  /api/v1/tasks/{id}/status  → (Admin only) Update status
```

---

### 5. Ownership Model

- Users can access **only their own tasks**
- Admin has **global visibility** across all users

This simulates **multi-user SaaS behavior**.

---

### 6. Protected APIs

- All task routes require a valid JWT
- Unauthorized access → `401 Unauthorized`
- Forbidden access → `403 Forbidden`

---

### 7. API Engineering Best Practices

- Versioned APIs → `/api/v1/...`
- Structured error handling
- Input validation using Pydantic
- Clean RESTful design

---

### 8. API Documentation

- **Swagger UI** — auto-generated by FastAPI at `/docs`
- **ReDoc** — available at `/redoc`

## 🗄️ Database Schema

### User

| Field    | Type    | Notes          |
| -------- | ------- | -------------- |
| id       | Integer | Primary Key    |
| email    | String  | Unique         |
| password | String  | bcrypt hashed  |
| role     | String  | `user`/`admin` |

### Task

| Field       | Type    | Notes                          |
| ----------- | ------- | ------------------------------ |
| id          | Integer | Primary Key                    |
| title       | String  |                                |
| description | String  |                                |
| status      | String  | `pending`/`running`/`completed`|
| user_id     | Integer | Foreign Key → User             |

## ⚙️ Setup Instructions

### 1. Clone Repository

```bash
git clone <your-repo-url>
cd BackEnd-Project
```

### 2. Backend Setup

```bash
cd Backend
pip install -r requirements.txt
cp .env.example .env
```

Configure your `.env`:

```env
DATABASE_URL=postgresql://user:password@localhost:5432/taskdb
SECRET_KEY=your-secret-key
```

Run the server:

```bash
uvicorn app.main:app --reload
```

Backend running at → `http://127.0.0.1:8000`

---

### 3. Frontend Setup

```bash
cd Frontend
npm install
npm run dev
```

Frontend running at → `http://localhost:5173`
